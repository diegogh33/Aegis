# Contributing

## Branch Strategy

Main branches

- main
- develop

Feature branches

feature/pr-XXX-description

Example

feature/pr-014-option-selector

---

## Commit Style

Examples

feat(selector): implement option ranking

fix(provider): handle missing delta

docs(architecture): update workflow

test(delta): add edge cases

---

## Pull Request Checklist

- Code compiles
- Tests pass
- Ruff passes
- MyPy passes
- Documentation updated

---

## Development Rules

Do not mix refactors with new features.

One feature per Pull Request.

Keep commits focused.

Document architectural decisions.
